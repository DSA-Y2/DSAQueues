# DSA Queues Collection 📚

Welcome to the ultimate Queue collection. We got everything from basic lines to circles and double-ended chaos.

## What's Inside?

### 1. [Simple Queue](./SimpleQueue)
The OG. First In, First Out. No drama. 
- **Array Implementation**: Fast but strict on space.
- **Linked List Implementation**: Flexible and chill.

### 2. [Circular Queue](./CircularQueue)
The eco-friendly one. 
- Recycles empty space so we don't waste memory. 
- Uses that `%` operator magic.

### 3. [Deque (Double Ended Queue)](./Deque)
The rule breaker.
- Add or remove from **both** the front and back.
- Maximum freedom.

## How to Run Stuff
Navigate to any folder and compile the `.cpp` files. 
Example:
```bash
cd SimpleQueue
g++ ArrayQueue.cpp -o app
./app
```

## Vibe Check
All code is written in C++ with standard libraries only (iostream). No bloat. Comments include explanations in plain English (and some slang).

Enjoy coding! 🚀
